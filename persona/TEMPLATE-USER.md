## 填完之后会发生什么

```
你的简版（12 项）
      ↓  「人设细化器」（固定提示词，见 EXPANDER-PROMPT.md）
详细版 v1（L0 锚 + L1 性格 + L2 说话 + 正反例对白）
      ↓  你可以逐层改、或只让某一层重生成
详细版 v2 → 装进 QQ
```

**细化器不会做的事**（写死在它的提示词里）：
- 不加你没提过的重大设定（不会凭空给她一个哥哥、一种恐惧症）
- 不写世界观、道具、关系网（那属于 L3，你自己决定要不要）
- 不超预算（L0≤400 / L1≤350 / L2≤800 字）

## 已知待定（用户 2026-10-20 提出）

### 1. 统一交互规范：每个字段都是「预设点选 + 自定义兜底」

不只是性格和雷区——所有填空最终都应该是这个形态：给一批现成选项让用户勾，同时留一格自由填。
理由：填表的人不知道"该写什么"，给选项降低了门槛；但只给选项又会限制个性，所以要留兜底。

已按此改造的字段：性格（20 个标签）、雷区（10 个标签）、说话偏好（三组单选）。

**待建**：`persona/lib/` 下的标签库（性格 / 雷区 / 口癖 / 关系 / 身份预设）。
标签库要能被"随机人设"直接复用——这是三个功能（默认/自填/随机）共用同一后端的落点。

### 2. 随机范围待商榷

要随机的到底是哪些东西，还没定。备选口径：

| 口径 | 说明 | 风险 |
|---|---|---|
| 只随机标签 | 主原型+性格+雷区 随机，其余用户填 | 太保守，出来都差不多 |
| 随机整张表 | 12 项全随机 | 可能抽出精神分裂的组合 |
| 分层随机 | 骨架（原型/性别/关系）随机 + 细节（口癖/对白）由细化器生成 | 比较可控，但需要细化器支持"部分填充" |

还要定三件事：粒度（整卡 / 单层 / 单项）、能否重 roll、随机结果能不能微调。
**先不实现，等主流程跑通再回来收。**
